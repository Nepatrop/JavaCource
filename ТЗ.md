# Проект
## Система управления сотрудниками предприятия

### Название проекта
Система управления сотрудниками предприятия

### Описание проекта
Веб-приложение для управления персоналом предприятия с возможностью регистрации сотрудников, ведения учета отделов и должностей, а также разграничением прав доступа для администраторов и обычных пользователей.

### Сущности системы

#### Employee (Сотрудник)
- ID (уникальный идентификатор)
- Имя
- Фамилия
- Отдел
- Должность
- Дата приема на работу
- Контактные данные

#### User (Пользователь системы)
- ID
- Логин
- Пароль (в зашифрованном виде)
- Роль (ADMIN/USER)
- Связанный сотрудник

#### Department (Отдел)
- ID
- Название отдела
- Руководитель (ссылка на Employee)
- Описание

### Функциональные требования

#### Для пользователя (USER):
- Просмотр списка сотрудников
- Поиск сотрудников по различным критериям
- Просмотр информации о своем профиле
- Изменение своих контактных данных

#### Для администратора (ADMIN):
- Полный CRUD для сотрудников
- Управление отделами
- Назначение ролей пользователям
- Просмотр статистики по отделам
- Доступ к системному мониторингу
- Генерация отчетов

### Технические требования

#### Архитектура:
- **Presentation Layer**: Spring MVC + Thymeleaf
- **Business Layer**: Spring Services
- **Data Layer**: Spring Data + Hibernate
- **Security**: Spring Security

#### Стек технологий:
- Java 21
- Spring Boot 3.x
- Spring Security
- Spring Data JPA
- Hibernate
- H2 Database (разработка) / PostgreSQL (продакшен)
- Thymeleaf
- Maven
- JUnit 5 + Mockito
- RestAssured
- Selenium
- Spring Boot Actuator
- Swagger/OpenAPI

#### База данных:
- Реляционная БД (PostgreSQL)
- Миграции через Hibernate DDL-auto
- Шифрование паролей (BCrypt)

### Безопасность
- Аутентификация по логину/паролю
- Авторизация на основе ролей (ROLE_ADMIN, ROLE_USER)
- Защита от CSRF атак
- Шифрование паролей
- Сессии с таймаутом

### Функциональные модули

#### 1. Модуль аутентификации и авторизации
- Регистрация новых пользователей
- Вход/выход из системы
- Восстановление пароля
- Управление ролями

#### 2. Модуль управления сотрудниками
- Добавление/редактирование/удаление сотрудников
- Поиск и фильтрация
- Импорт/экспорт данных
- Назначение отделов

#### 3. Модуль отчетности
- Статистика по отделам
- Отчеты по найму/увольнению
- Аналитика зарплат

#### 4. Модуль системного администрирования
- Мониторинг через Actuator
- Логирование операций
- Резервное копирование
